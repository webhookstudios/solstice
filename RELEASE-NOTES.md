# Solstice 1.1.0

Solstice is the new name for Gleam. It now has the Sedge look shared by every webhookstudios app: one set of colors, fonts and icons, in light and dark mode.

- New icon, colors and fonts. Window titles and headings use the Sedge serif.
- A main menu with an About window.
- The package and command are now called `solstice` (it was `gleam`). Installing it replaces the old package.
- Your saved brightness from Gleam is copied over the first time Solstice starts.
- Everything works exactly as before. Your settings and presets carry over.

Install:

```bash
sudo apt install ./solstice_1.1.0_all.deb
```
